# WorkSphere - Employee Management System

A robust, enterprise-grade **Employee Management System** built with **Spring Boot** and **Thymeleaf**, designed to streamline employee data management, tracking, and administration.

## 🚀 Tech Stack & Features

* **Backend Framework:** Spring Boot (v3.5.0)
* **Language:** Java 17
* **Database & ORM:** MySQL, Spring Data JPA[cite: 15]
* **Templating Engine:** Thymeleaf[cite: 15]
* **Boilerplate Reduction:** Project Lombok[cite: 15]
* **Build Tool:** Apache Maven (Wrapper included)[cite: 13, 14, 15]
